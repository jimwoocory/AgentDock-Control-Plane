# CP-01 执行合同

Outcome：用户能够打开 localhost 控制台，看到家中 AgentDock 的真实任务、步骤、状态、历史，以及明确的数据来源与采集时间。

依赖：上游固定基线、pnpm 安装、可读 AgentDock 本地任务文件。源写操作为零。

顺序：安装与基线检查；实际格式审查；适配边界的失败测试；实现有大小与字段约束的只读采集与独立 SQLite 快照；认证 API；中文观察页面与项目关联；运行脚本；测试构建；独立代码审查；提交与 main 复验。

保留任务的实际外部 ID。步骤只是步骤，不宣称来源具备任意依赖 DAG。未报告 agent/heartbeat 的任务显示未知，不从标题猜测。源读取失败不能返回成功空集或删除旧历史。

Allowed Paths 见任务板；AgentDock Core、配置、任务文件、会话与现有项目均不得修改。真实数据不进入测试夹具或文档。
