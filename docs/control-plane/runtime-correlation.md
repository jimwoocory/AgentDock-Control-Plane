# 任务与执行会话关联

CP-15 扩展现有只读控制台，沿用节点的 Agent 管理字段关联执行会话。管理关联与来源自报关联分开标注；不会启动、暂停、恢复或停止 Worker。

任务详情新增“任务执行关联”：任务状态、会话观测状态、关联 Worker/会话标识、最近一轮生命周期事件、实际当前动作/心跳、来源进行中检查点及其更新时间。任务 active 不证明 Worker Running，会话一轮结束不等于业务任务完成。

未关联、对应会话不在当前快照、会话证据已过期或未发现、来源快照失败/过期、明确关联冲突时，当前执行保持未知。多个当前任务共享一个管理会话或多个来源会话自报同一任务也显示冲突，不根据标题、项目名、检查点或采集时间猜测运行状态。

正常所有者会话通过现有节点 Agent 字段保存管理关联，其他管理字段保持原样。原生 MCP get_task 对原始来源任务 ID 和节点 ID 返回一致来源详情，并附加 runtime 证据；list_agents 的任务和项目筛选先于 limit 应用。未筛选查询保持原行为。身份、权限、现有审批语义和八个只读工具集合不变。

复用采集器已有的受限生命周期字段，不新增提示词/聊天正文采集，不写入 AgentDock Core 或来源任务。本轮只关联用户指定的真实任务作为读回样例，具体 ID 和会话证据仅在忽略目录保留。

新增模型/API/实际 React 渲染回归覆盖管理与自报关联、缺失/过期/冲突、来源检查点、双 ID 查询、筛选与数量限制。独立复审发现管理关联A/来源自报B冲突负例，已补失败回归并修复；最终六项专项测试通过，复审批准。已合入main，主分支完整cloud测试84/84和私有Worker构建通过。原私有Site源码访问被自动审批拦截，线上发布与读回尚待范围批准，任务保持REVIEW，不标DONE。
