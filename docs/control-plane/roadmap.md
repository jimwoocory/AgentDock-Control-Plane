# 路线图

P0-A（CP-01，历史基线）：本地运行、项目筛选、任务/步骤树、真实来源状态与历史、持续只读同步。

完整 P0（CP-02 / CP-02-UI / CP-03）：独立 SQLite 项目/任务/Agent 模型、Epic/Feature/Task/Subtask 层级、依赖 DAG、图与树视图、项目和本地节点创建、真实只读来源、Agent 状态证据与历史。

Gate：

1. 浏览器能够创建项目和完整任务树，并在刷新后保留。
2. 依赖可视化、验收条件与优先级可查看和编辑；拒绝循环、无效父级与跨项目关联。
3. Agent 状态根据实际会话或生命周期证据显示，缺失、未知、过期和接口不可用显式区分；采集时间不等于心跳。
4. 查看真实执行事件、本地管理历史与 Agent 观察历史；读取失败保留最后事实。
5. USVDS2、BMAD、Toonflow、Google-TTS、Research Lab 的 50 个 Task 可隔离管理；夹具与实际来源分库。
6. 来源文件哈希不变、Core 健康、未授权访问及运行时控制被拒绝；相关测试与生产构建通过、分支提交合入 main 后复验。

P1：经后续单独能力验证后添加暂停/恢复/重试、Human Approval Gate、Decision Log 与 Artifact Registry。原始「控制验收」的暂停/恢复/审批属于 P1；P0 的优先级只是本地管理字段，不控制 Worker。
