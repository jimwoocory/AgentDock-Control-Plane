Gate：

1. 浏览器能够创建项目和完整任务树，并在刷新后保留。
2. 依赖可视化、验收条件与优先级可查看和编辑；拒绝循环、无效父级与跨项目关联。
3. Agent 状态根据实际会话或生命周期证据显示，缺失、未知、过期和接口不可用显式区分；采集时间不等于心跳。
4. 查看真实执行事件、本地管理历史与 Agent 观察历史；读取失败保留最后事实。
5. USVDS2、BMAD、Toonflow、Google-TTS、Research Lab 的 50 个 Task 可隔离管理；夹具与实际来源分库。
6. 来源文件哈希不变、Core 健康、未授权访问及运行时控制被拒绝；相关测试与生产构建通过、分支提交合入 main 后复验。
