# 完整 P0 Implementation Plan

> **For agentic workers:** Use executing-plans for root implementation and dispatching-parallel-agents for independent UI/runtime investigation, with separate ownership and review gates.

**Goal:** 完成原始 P0 的项目/任务树/依赖图/Agent状态/历史/多项目验收，不修改 AgentDock Core。
**Architecture:** SQLite 本地管理模型 + AgentDock 只读投影 + 独立Agent观察适配器。React SVG依赖图与任务树使用同一节点合同，记录来源与陈旧状态。
**Tech Stack:** 既有 React/TypeScript/Next.js/better-sqlite3，Windows Node>=22.18，不增加图形依赖。
**Spec:** docs/superpowers/specs/2026-10-11-full-p0-design.md

## Global Constraints

- 所有业务实现位于独立 codex/CP-02-full-p0 worktree，不在 main 开发。
- 不写 AgentDock Core、配置、任务/会话、凭据；不启动或派发 Agent 工作。
- 只读来源与本地管理信息分开；任务active不代表Agent running，采集时间不等于心跳。
- 真实数据和登录信息不进入Git；50任务夹具另用数据库明确标注。
